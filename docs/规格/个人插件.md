# QmQQNT 个人插件

## 已确认范围

- 基于琉璃独立维护个人插件，不再以兼容其他插件为设计目标。
- 安装个人插件后备份并移除其他插件，保留 LiteLoader 框架。
- 解除 QQ 调色盘默认主题限制，保留原调色盘设置。
- 左侧导航按最新要求默认常驻，为会话列表预留宽度；顶栏默认自动隐藏，两者分别可配置。
- 群资料和个人资料抽屉、设置页共用材质参数。
- 修复成员标题裁切，统一承载层圆角，修复菜单字号与通知设置中的胶囊样式污染。
- 字号直接输入像素值，例如 `14px`，不用拖动滑条。
- 壁纸以窗口为固定坐标系，保留宽高比；快速切换不得提交过期解码和取色结果。
- 气泡按 Telegram macOS 原生版方向改造；主色按壁纸颜色占比选择，避免极少量鲜艳色抢占主色。
- 动画统一所有权和生命周期；支持中断、快速反向操作和系统减少动态效果设置。
- 侧栏底部同时提供邮箱和收藏。
- 完整 Markdown：Linkify、Typographer、代码高亮随明暗主题切换。
- 消息复读、消息加一、防撤回、侧键返回主列表、移除回复自动附带的 @、替换小程序卡片。
- 显示发送时间与消息元数据；总消息数、序号和本地观察计数必须明确区分。
- LLM 支持生成草稿和白名单自动回复，默认草稿。模型端点、模型名和密钥在设置中填写。
- IPC 自动领取红包；语音红包通过 TTS 合成口令再发送。相关自动化默认关闭。

## 验证边界

按照用户规则，默认只补测试和静态审阅，不编译、不运行测试、不启动 QQ 验证。
不通过实际收发消息、语音或领取红包来验证功能。

## 实现进度

- 已拆出取色、壁纸、动画、设置与消息业务模块。
- 已移除每 1.5 秒扫描整页后修补样式的逻辑，使用语义颜色变量和绘制前装饰。
- 已补充对应行为测试代码，未执行。
- 已提供备份、哈希核对、旧插件移出和失败恢复的安装脚本。
- QQ 界面、当前版本 IPC、红包类型识别与真实收发仍未验证，不能据此宣称运行通过。
- PR 与本机安装的实际结果记录在交付说明和安装记录中。
